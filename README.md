# DroneRush

Нейронка запилила эту ридмишку, потому что влом делать самому

DroneRush — это проект на C++ для разработки игры/демо с дронами, собранный через CMake.

## О проекте

Этот репозиторий содержит основу для игровой логики, графики и систем управления, которые можно использовать для разработки прототипа или небольшого проекта в жанре воздушного симулятора/аркады.

## Быстрый старт

```bash
cmake -S . -B build
cmake --build build
```

После сборки можно запустить собранный исполняемый файл из директории `build`.

## Структура проекта

- `src/` — исходный код проекта
- `include/` — заголовочные файлы
- `assets/` — ресурсы и ассеты
- `build/` — собранные файлы после запуска CMake
